# Security Policy

Lightchain takes the security of its software, smart contracts and network seriously. Thank you for helping keep Lightchain and its users safe.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, pull requests, discussions or social media.**

Report them privately through GitHub:

1. Open the affected repository on GitHub.
2. Go to the **Security** tab and click **Report a vulnerability**.
3. Describe the issue and submit the report. Only the maintainers can see it.

Please include as much of the following as you can:

- The affected repository, component, contract address or network (mainnet, testnet or devnet)
- The type of issue and its potential impact
- Steps to reproduce it, or a proof of concept
- Any suggested fix or mitigation

## What happens next

We will acknowledge your report, investigate it, and keep you informed of our progress. Please give us reasonable time to fix the issue before disclosing it publicly, and do not access, modify or delete data that is not yours while researching.

## Scope

This policy covers all repositories in the Lightchain GitHub organization, including the network software, smart contracts and applications they contain. Third-party code and services that Lightchain uses are covered by their own maintainers' security policies.
